## Selected work

### Research software (psychology / cognitive science)

- **[BrmsGeneratorResearcher](https://github.com/nadavWeisler/BrmsGeneratorResearcher)** — bRMS experiment generator built for the Green Lab (HUJI).
- **[jsPsychRmsPlugin](https://github.com/nadavWeisler/jsPsychRmsPlugin)** — jsPsych plugin for the repeated masked suppression (RMS) paradigm.
- **[jsPsychConjunctiveCPT](https://github.com/nadavWeisler/jsPsychConjunctiveCPT)** — jsPsych plugin for the Conjunctive Continuous Performance Task.
- **[MaskingGenerator](https://github.com/nadavWeisler/MaskingGenerator)** — small web tool for generating mask images for psychology experiments ([demo](https://nadavweisler.github.io/MaskingGenerator/)).
- **[PavloviaSignReport](https://github.com/nadavWeisler/PavloviaSignReport)** — Python package/CLI that turns Pavlovia CSV exports into per-participant and summary Word reports.

### Health / clinical data tools

- **[MedCodeTranslator](https://github.com/nadavWeisler/MedCodeTranslator)** — medical code lookup (ICD, ATC, LOINC, and related terminologies) with autocomplete across web and mobile.

### Related
